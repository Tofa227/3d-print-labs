# 3D Print Labs

Магазин готовых 3D-печатных изделий: один файл `index.html`, без сборки и бэкенда.

Открыть: дважды кликнуть `index.html` (нужен интернет для шрифтов и three.js с CDN).

- Самовывоз: Tab, Siófok; пункт выдачи и доставка на дом
- Личный кабинет: заказы, купоны, профиль (`#account`)
- Демо-админка: `#admin`, логин `admin`, пароль `admin`
- Данные хранятся только в localStorage браузера (демо, без сервера)
